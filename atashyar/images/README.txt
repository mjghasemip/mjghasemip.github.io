===== پوشه تصاویر (images/) =====

۱) تصویر کارت بانکی (برای صفحه پرداخت):
   card.png   ← عکس کارت را با همین نام اینجا بگذار

۲) عکس‌های محصولات (اختیاری):
   cube-12.jpg   → مکعب ۱۲ عددی
   cube-16.jpg   → مکعب ۱۶ عددی (قوطی)
   stove.jpg     → اجاق سفری

   سپس در js/config.js برای هر محصول بنویس:
     image: 'images/cube-12.jpg',

اگر card.png نباشد، یک کارت گرادیانت CSS جایگزین می‌شود.
اگر عکس محصول نباشد، آیکون 🔥 نشان داده می‌شود.
